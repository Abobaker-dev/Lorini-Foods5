# Lorini Foods – front-end restaurant website
Run on Windows: unzip, then double-click `start.bat` (or `index.html`). Internet is needed for fonts, icons, photos and the map.
Optional local server: `python -m http.server 8000` in this folder, then open http://localhost:8000
Structure: emails/ (HTML email templates for Zapier) · index.html · css/style.css · js/script.js · assets/images (put your own photos here)
Login/Create Account is a localStorage DEMO and is not secure.
